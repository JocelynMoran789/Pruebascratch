# 🟠 Scratch

> ### 💻 Aprende a programar de forma creativa, visual y divertida

## 🎯 ¿Qué es Scratch?

**Scratch** es una plataforma educativa que permite aprender programación utilizando **bloques visuales** que se conectan como piezas de rompecabezas.

Con Scratch puedes crear:

🎮 **Juegos** · 🎨 **Animaciones** · 📖 **Historias** · 🧪 **Simulaciones** · 📚 **Proyectos educativos**

---

## 🧩 Conceptos básicos

| Concepto           | ¿Para qué sirve?    |
| ------------------ | ------------------- |
| 🔄 **Ciclos**      | Repetir acciones    |
| 🔀 **Condiciones** | Tomar decisiones    |
| 📦 **Variables**   | Guardar información |
| ⚡ **Eventos**      | Iniciar acciones    |
| 💬 **Mensajes**    | Comunicar sprites   |
| 🎮 **Sensores**    | Detectar acciones   |

---

## 🧍 Elementos principales

### 🧍 Sprites

Son los **personajes y objetos** que podemos programar.

### 🌄 Escenario

Es el lugar donde ocurre nuestro proyecto. Podemos cambiar fondos y crear diferentes escenas.

### 🧱 Bloques

Son las instrucciones que controlan los personajes y objetos.

---

## 🧱 Categorías de bloques

🔵 **Movimiento** → mover personajes
🟣 **Apariencia** → disfraces y textos
🩷 **Sonido** → música y efectos
🟡 **Eventos** → iniciar acciones
🟠 **Control** → ciclos y condiciones
🔵 **Sensores** → detectar acciones
🟢 **Operadores** → cálculos y comparaciones
📦 **Variables** → almacenar datos

---

## 🎮 ¿Qué podemos crear?

* 🎮 **Videojuegos**
* 🎨 **Animaciones**
* 📖 **Historias interactivas**
* 🚦 **Simulaciones**
* 🧮 **Actividades educativas**

Podemos añadir **⭐ puntos, ❤️ vidas, 🏆 niveles, ⏱️ tiempo, 🔊 sonidos y enemigos**.

---

## 🧠 Variables y decisiones

Las variables permiten guardar información:

```text
⭐ Puntos = 0
❤️ Vidas = 3
🏆 Nivel = 1
⏱️ Tiempo = 60
```

Las condiciones permiten tomar decisiones:

```text
SI toca al enemigo
      ↓
  Pierde una vida
```

---

## 🔄 ¿Cómo funciona?

```text
⚡ Evento
   ↓
🧩 Instrucciones
   ↓
🔀 Condición
   ↓
🎮 Acción
   ↓
⭐ Resultado
```

Por ejemplo:

**Presionar JUGAR → mover personaje → recoger objetos → ganar puntos.**

---

## 🚀 ¿Por qué aprender Scratch?

Scratch ayuda a desarrollar:

🧠 **Pensamiento lógico**
💡 **Creatividad**
🧩 **Resolución de problemas**
💻 **Pensamiento computacional**

Además, sus conceptos sirven como base para aprender lenguajes como **Python, JavaScript, Java y C++**.
